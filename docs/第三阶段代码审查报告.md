# 第三阶段代码审查报告

日期：2026-10-08
范围：`server/`、`web/`、启动脚本、依赖、文档，以及与核心模块的接口边界。

## 审查结论

当前没有发现阻断本地开发的 Critical 问题。FastAPI 只负责适配，不改变已验证的 RAG/Agent 算法；前端不持有 API Key，也不直接请求 DeepSeek。

## 问题分级与处理

### High

**H-1 上传路径穿越与类型校验**：上传接口必须拒绝任意路径和未知扩展名。已修复：使用 `Path(filename).name`、白名单扩展名、50 MB 限制，并且重索引仅接受 `data/uploads` 内路径。

**H-2 密钥暴露面**：设置接口可能误返回环境变量。已修复：`/api/settings` 只返回 `api_configured` 和模型名称，不返回 Key；前端和 SSE 也不接收 Key。

**H-3 前端假数据风险**：知识库和引用如果使用静态数据会造成错误溯源。已修复：文档列表、上传结果、Citation 和 tool trace 全部来自真实后端对象；测试覆盖 SSE 引用持久化。

### Medium

**M-1 服务启动下载模型**：启动 API 时初始化模型会导致超时。已修复：`ResearchAssistantService` 懒加载，健康检查不触发模型下载。

**M-2 Web 会话与 Agent memory 双存储**：删除会话不清理 Agent memory。当前保留隔离设计以避免破坏核心记忆；已在交接文档标注，后续可增加清理钩子。

**M-3 取消语义**：RAG 客户端断连会设置取消信号并关闭 OpenAI 兼容 SSE 流；同步 Agent 循环仍不能取消，列为技术债务。

**M-4 大文件任务**：当前上传请求在线程池中索引，超大 PDF 会占用请求。下一步改为后台任务 + 状态查询；本阶段以真实可用为优先。

### Low

**L-1 前端 bundle 较大**：KaTeX 和 highlight.js 使 Vite 给出 chunk >500KB 警告。功能无阻断，后续可按路由拆包。

**L-2 启动脚本依赖 Windows `start` 窗口标题**：`stop_web.bat` 只终止标题匹配的两个窗口，不会触碰其他 Python/Node 进程。

## 安全与质量检查

- CORS 默认仅允许本机 5173，可由 `PAPERMIND_CORS_ORIGINS` 明确配置。
- Pydantic 对聊天、会话标题、检索模式、Top-K 和候选池做校验。
- 统一错误响应使用 `{"detail": {"error": "..."}}`；SSE 失败发送 `error` 事件。
- 日志和核心模块的既有脱敏逻辑保留；新增 Web 存储不写 API Key。
- `web/node_modules`、构建产物、`.env`、模型、课程材料、数据目录均被 Git 忽略。
