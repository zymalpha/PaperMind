# 第二阶段开发记录：高级 RAG + Agent 核心能力

## 范围

基于第一阶段提交 `e9143ee` 继续增量开发。保留现有 Streamlit 入口、文档解析、DeepSeek OpenAI 兼容客户端、Chroma 持久化和本地 Embedding。本阶段未重构界面，也未制作正式评测报告或 PPT。

## 实现内容

- 新增固定长度、递归和句段语义三类分块策略，均保留文件名、页码、文档 ID 和 chunk ID。
- 新增中文/英文轻量分词 BM25、手写 RRF，以及 `vector`、`hybrid`、`hybrid_rerank` 三种检索模式。
- 接入本地 BGE CrossEncoder Reranker；加载或推理失败会返回混合检索结果并在响应中标注降级原因。
- 索引支持内容哈希幂等导入、强制重建、文档清单和删除；同名、内容变化的托管上传可替换旧版本。
- 加强 RAG 上下文拼接和证据规则，增加与精确证据集绑定的 SQLite 语义缓存、低相关性/生成异常降级及请求 Token、耗时日志。
- 新增 ReAct Agent、工具注册表和 8 个工具；工具参数采用 JSON Schema 校验。Agent 支持独立会话、滑动窗口、旧轮次摘要、并行工具、超时、重复调用拦截和逐次工具日志。
- 补充递归敏感字段及 API Key 样式字符串日志脱敏；新增 `scripts/run_agent.py` 命令行入口。
- 目录职责保持分离：应用实现位于 `src/research_assistant/`，测试在 `tests/`，操作脚本在 `scripts/`，阶段文档在 `docs/`，运行数据在被忽略的 `data/`。

## 测试与真实数据验证

- 自动化测试覆盖分块元数据、BM25/RRF、缓存隔离、缺少重排模型时降级、工具注册和校验、ReAct 调用/会话隔离/日志、迭代上限及超时与脱敏。
- 阶段开发期间执行过真实论文集成验证：使用 arXiv `2005.11401`《Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks》，完成索引（142 chunks）、纯向量与 BM25+RRF 检索，并检查了文件名和页码元信息；DeepSeek RAG 生成返回约 5 条带页码引用。Agent 的计算器工具曾完成真实 API 工具调用（`137 * 29 = 3973`）。这些是基础冒烟验证，不构成准确率评测。
- BGE Reranker 首次下载/加载超过 4 分钟，未能确认模型成功加载及排序效果。因此此项代码已接入并提供失败降级，但**模型实际运行验证仍待完成**。需要能从模型仓库下载 `BAAI/bge-reranker-base` 后，再进行本地验证。
- 通过 PowerShell 管道进行中文 Agent 集成请求时遇到输入编码损坏，模型因此选错工具；这是命令行编码路径的限制，非工具注册或 schema 测试失败。应通过 UTF-8 输入环境/交互调用重新验证中文指令。
