# 第三阶段开发记录：Web 前端与系统集成

日期：2026-10-08

## 目标与迁移方案

保留 `src/research_assistant/` 和 `app.py`，新增一个薄 FastAPI 适配层，前端只调用后端接口。RAG/Agent 的索引、引用和工具逻辑不复制到 TypeScript；Web 会话展示单独使用 SQLite，Agent 原有 memory 继续由核心模块管理。

## 实际实现

1. 新增 `server/main.py`：懒加载服务，提供健康/设置、会话 CRUD、批量上传、重索引、删除、SSE 聊天。
2. 新增 `server/storage.py`：会话标题、消息、Citation 和 tool trace 持久化。
3. 新增 `web/`：Vite + React + TypeScript；Lucide 图标、CSS design tokens、响应式侧栏、浅色/深色主题。
4. Chat 工作台消费真实 SSE：`token`、`citations`、`tool`、`final`、`error`、`done`；回答用 react-markdown + GFM + KaTeX + highlight.js 渲染。
5. 知识库页面调用真实上传和索引接口，显示 chunks、策略、状态，支持重索引和删除。
6. 设置页面修改检索模式、Top-K、候选池，并通过 `PATCH /api/settings` 应用到后端；健康状态区分已加载、未加载和未配置。
7. 新增 `start_web.bat` / `stop_web.bat`，并补充依赖、忽略规则和文档。

## 真实运行说明

真实论文上传会触发本地 Embedding/Reranker；真实聊天会调用 DeepSeek 并产生费用，因此本轮自动化测试使用了确定性 fake engine 验证 SSE 协议和持久化。用户验收时应先确认 `models/` 模型完整，再用一篇论文执行一次真实问答。

## 已知限制

- Agent 核心仍是同步 `run()`，Web 暂时在完成循环后一次性发送工具轨迹；RAG token 是实时流式。
- RAG 客户端断连会触发取消信号并关闭 OpenAI 兼容流；底层同步 Agent 循环仍不能取消。
- 尚未加入 Playwright 自动化截图验收；本轮完成前端编译和 API 自动化验证，但未做真实浏览器交互、服务启动冒烟或真实论文 + DeepSeek 端到端验收。
