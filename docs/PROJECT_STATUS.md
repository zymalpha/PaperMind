## 已知限制与技术债务

1. 元信息提取仍是面向常见论文排版的启发式解析，不替代 Crossref/arXiv 元数据接口；PDF 首页异常排版可能需要人工核对。
2. `deepseek-flash` 的工具选择由模型决定，偶发多调用不属于编码损坏；Agent 有最大轮数、超时、参数校验和重复调用保护。
3. BGE Reranker CPU 推理较慢，首次安装需要约 1.1 GB 权重；权重位于被 Git 忽略的 `models/`，不上传仓库。
4. 当前真实验证是基础集成冒烟，不是第四阶段的准确率、延迟或成本评测。
